点歌同学怎么做

  1. 打开{{点歌入口}}，登录账号。
  2. 搜歌，写清：歌名、歌手、想说的话、点给谁。
  3. 提交，等{{审核时限}}内审核。
  4. 在"我的点歌"查状态：待审核→已通过→已播放。
  • 开放时间：{{点歌开放时间}}
  • 播放时段：{{播放时段}}
  • 能点：正版、曲风正常的歌 + 想说的话。
  • 不能点：违规/低俗/侵权/攻击性，或泄露他人隐私。
  • 被驳常见：歌名歌手错、音源失效、敏感词、重复刷。
  • 有问题：2498517208@qq.com

广播站成员怎么做

  1. 收歌：到点歌系统取当日提交。
  2. 审核：通过 / 驳回 / 待补充。
  3. 排单：按播放时段排入队列。
  4. 播前检查：歌名·音源·版权·敏感词·音量·时间。
  5. 播放 → 记录：留痕歌单/审核/播放。
  • 每日：设备自检、网络在线、备份记录。
  • 账号：仅授权成员登录，密码每月换。
  • 故障：没声查功放/音源；放错立即切下一首；误播禁曲马上停播并上报。
  • 交接：歌单/队列/异常当面说清，双方签字。
  • 红线：不播未审歌、不播侵权歌、不泄露同学信息。

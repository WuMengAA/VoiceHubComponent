二、点歌步骤

  1. 打开{{点歌入口}}，登录你的账号。
  2. 搜索或输入想点的歌，写清下面四项：歌名、歌手、想说的话、点给谁。

四、被驳回常见原因

  • 歌名/歌手写错或查不到音源；
  • 歌词或内容涉及敏感词、低俗、侵权；
  • 点给了不存在的人或泄露他人信息；
  • 同一首歌短时间内重复点太多。

五、怎么查有没有被选中

在{{点歌入口}}的"我的点歌"里看状态：待审核 → 已通过（排队中）→ 已播放。通过的歌会按播放时段安排，不一定当天播。

六、隐私和版权提醒

  • 只填必要的点歌信息，不收集无关隐私。
  • 请点正版歌曲；侵权、搬运音源不予播放。
  • 广播站/第三方负责审核与播放，校方负责监管。

八、常见问题

1. 点错了能撤回吗？
在"我的点歌"里未审核前可撤销；已审核需联系客服。
2. 为什么一直"待审核"？
审核在{{审核时限}}内完成，高峰期会稍慢，请耐心等。
3. 能指定几点播吗？
不能精确指定，按播放时段和排队顺序安排。
4. 被驳回能再点吗？
可以，修改后重新提交；同一问题反复提交仍会被驳。
5. 想点的歌搜不到怎么办？
确认歌名/歌手拼写，或换一个版本；仍不行请联系客服。
